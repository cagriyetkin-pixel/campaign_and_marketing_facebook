# 📊 Data Analytics Project on Facebook Campaign

This repository contains data analytics and marketing performance projects developed using Python, Pandas, Matplotlib, and Seaborn.

## 📁 Repository Structure
- `02_Marketing_facebook_analizi.ipynb` — Facebook ad campaigns performance (CTR, CPC, ROMI).
- `facebook_ads_data (2.0).csv` — Dataset for Facebook advertising performance analysis.

## 🛠️ Tools & Libraries
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
